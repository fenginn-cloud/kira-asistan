# Emince Sözlük 🥜

Arkadaşımız **Emin**'in kendince icat ettiği efsane kelimelerin resmi (şaka) sözlüğü.

> ⚠️ Bu klasör `kira-asistan` uygulamasından **tamamen bağımsızdır**. Ana uygulamanın
> koduyla hiçbir ilgisi yoktur, hiçbir dosyasını etkilemez.

## Nasıl açılır?
`emince/index.html` dosyasına çift tıkla — tarayıcıda açılır. Kurulum, sunucu, hiçbir şey gerekmez.

## Özellikler
- 🎰 Rastgele Emince kelime makinesi (çevir çevir!)
- 🔊 Sesli söyleme (tarayıcı destekliyorsa)
- 🔍 Kelime arama
- ❤️ Beğen butonları
- 🥜 Uçuşan fıstıklar

## Kelime eklemek
`index.html` içindeki `words` dizisine yeni bir satır ekle:
```js
{w:"Kelime", t:"tür", m:"Anlamı", ex:"Örnek <b>cümle</b>."},
```
